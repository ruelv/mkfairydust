This is a script that builds the asahi linux fairydust branch based on the script in [bharambetejas/asahi-fairydust-display](https://github.com/bharambetejas/asahi-fairydust-display).
It's mostly the same as of now, just easier to read.
Tested on the apple m1 air with [fairydust 59b64a2cbf154b4315f300d1128a5aeb4616d010](https://github.com/AsahiLinux/linux/commit/59b64a2cbf154b4315f300d1128a5aeb4616d010) and initial config from asahi linux's repo kernel 7.2.12-402.asahi.fc45.
